\chapter{Contribution: reduction rules for recursors (iota)}
\label{chap:contrib-iota}

\section{Goal}
\begin{itemize}
\item \lead{Given} \texttt{VInductDecl.WF} and \texttt{addInduct} unproved, and the
refinement's \texttt{AddInduct} carrying no constructor: the modelled theory had no account
of $\iota$.
\item \lead{Goal} give every recursor of every inductive block a reduction rule, and prove
sound the environment operations that install it.
\item \lead{In short} treat $\iota$ as a schematic rewrite rule: a registry added to
\texttt{VEnv}, fired by one generic \texttt{IsDefEq} constructor.
\end{itemize}

\section{Main results}
\label{sec:contrib-iota-claims}
\begin{itemize}
\item \stProved{} \ref{thm:indlem-add-induct-wf}: \texttt{addInduct} is sound, axiom
footprint \texttt{propext}, \texttt{Classical.choice}, \texttt{Quot.sound}.
\item \stProved{} \ref{thm:add-quot-wf}, \ref{thm:check-eq-type-ok}: the quotient extension
is sound, replacing a proof that becomes false, not merely vacuous, once inductives are
enterable.
\item \stProved{} \ref{thm:aligned-add-induct}, \ref{thm:tr-env-iota-rec}: the refinement's
bookkeeping and $\iota$-lookup are derived, not assumed.
\item \stTainted{} \ref{thm:vtc-iota-reduce-core}: the type checker's recursor reduction
matches a registered rule exactly; taint reaches it through \texttt{TrProj.uniq}.
\item \stTainted{} \ref{thm:indparams-cr-defeq-of-induct}: Church--Rosser for the
\texttt{Params} instance, on a single-block environment; taint reaches it through master's
own \texttt{NormalEq.parRed}.
\item \stSorry{} \ref{thm:wf-patsstrong}: every registered rule preserves types (see What is
not proved).
\end{itemize}

\section{Open items}
\label{sec:contrib-iota-hygiene}
\begin{itemize}
\item \ref{thm:wf-patsstrong} needs type-former injectivity, itself unproved.
\item Nothing in the project constructs an \texttt{AddInduct} witness for a real
declaration: \texttt{addDecl.WF}'s inductive case is still \texttt{sorry}.
\item \ref{thm:vtc-iota-reduce-core} has no consumer: the adjacent \texttt{reduceRecursor.WF}
is still \texttt{sorry}.
\item \texttt{DefEqsAsPats} confines \ref{def:indparams-toparams} to environments with no
\texttt{def} and no quotient rule.
\item \ref{def:indparams-toparams}, its specialisation, and
\ref{thm:indparams-cr-defeq-of-induct} have no consumer elsewhere in the project.
\item K-like reduction is recorded (\texttt{VRecursor.k}) but never registered as a rule.
\end{itemize}
